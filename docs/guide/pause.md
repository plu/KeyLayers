# Pause and emergency stop

**Pause Remapping** in the status area turns remapping off: every key does what it normally does.
**Resume Remapping** turns it back on.

<Shot name="app/status-paused" alt="KeyLayers' status area: Remapping paused, with a Resume Remapping button" />

If remapping gets in your way and you can't reach the window, press

**Left Control + Left Option + Left Command + Escape** (⌃⌥⌘⎋)

on the keyboard. It pauses remapping just like the button, from anywhere.

The helper also has a menu in the menu bar, which shows the keymap and layer you're on and can quit it.
Quitting the helper leaves your keyboard fully normal until you start it again from the KeyLayers window
(**Start Helper**) or log in again.
