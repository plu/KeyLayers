# Updates

KeyLayers checks for new versions by itself and offers to install them. To check now, choose
**KeyLayers → Check for Updates…**.

When you install an update, KeyLayers relaunches, and within a few seconds the helper and the input service
restart with the new version too. Your keymaps, settings and the three approvals from the
[setup](./setup) stay as they are: there's nothing to approve again.

The release notes for every version are on the
[releases page](https://github.com/plu/KeyLayers/releases).
