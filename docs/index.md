<LandingSection eyebrow="Why KeyLayers" title="Made for the road." narrow>

At my desk I type on a [UHK](https://ultimatehackingkeyboard.com), the Ultimate Hacking Keyboard, and I
live in its layers: arrows, Home, End and Page Up under the home row, a Mod key away. On the road, with
only the MacBook, all of that was gone, and I kept getting lost on a keyboard I've used for years.

So I built KeyLayers: the layers I'm used to, on the keyboard I have with me. It does one thing, layers,
and stays out of the way otherwise.

</LandingSection>

<LandingSection eyebrow="Features" title="Your keyboard, in layers.">

<p class="landing-group">Layers</p>
<div class="feature-grid">
<FeatureCard title="Hold a key, get a layer" shot="app/keyboard-mod" alt="The Mod layer in KeyLayers: arrows on H J K L, Home, End and page keys" zoom="190%" focus="72% 42%">
While you hold a layer key, its layer replaces the keys underneath. Keys it doesn't map fall through, so
the rest of your keyboard stays as it is.
</FeatureCard>
<FeatureCard title="Change any key" shot="app/key-editor" alt="The key editor: Caps Lock sends Escape with Command and Shift, and holds for the Mod layer" zoom="360px" focus="center top">
Click a key and pick what it does: a keypress with modifiers, a media key, a layer, another keymap or a
macro. Changes apply right away.
</FeatureCard>
</div>

<p class="landing-group">Automation</p>
<div class="feature-grid">
<FeatureCard title="Macros" shot="app/window-macro" alt="A macro in KeyLayers with key, text and delay steps" zoom="150%" focus="62% 0%">
A list of key taps, typed text and pauses that one key plays. Typed for your keyboard layout.
</FeatureCard>
<FeatureCard title="Settings that stay small" shot="app/settings" alt="KeyLayers settings: double-tap timeout, layer overlay, menu bar and login options" zoom="460px" focus="center top">
Double-tap timing, a short overlay when you lock a layer, the keymap and layer in the menu bar, and
whether the helper starts at login.
</FeatureCard>
</div>

<p class="landing-group">Setup</p>
<div class="feature-grid">
<FeatureCard title="It tells you what's missing" shot="app/status-input-monitoring" alt="KeyLayers' status area asking for Input Monitoring" zoom="140%" focus="left top">
macOS wants three approvals. The status area says which one is next and opens the right place in System
Settings. The <a href="./guide/setup">setup guide</a> shows every step.
</FeatureCard>
<FeatureCard title="Pause any time" shot="app/status-paused" alt="KeyLayers' status area: Remapping paused" zoom="140%" focus="left top">
One click, or Left Control + Left Option + Left Command + Escape from anywhere, and every key does what it
normally does.
</FeatureCard>
</div>

<div class="privacy-grid">
<div>
<h3>Read, remapped, gone</h3>
<p>To remap your keys, KeyLayers reads them, which is why macOS asks for Input Monitoring. Each key is
remapped the moment you press it. Nothing is logged, stored or sent anywhere.</p>
</div>
<div>
<h3>No network, except updates</h3>
<p>The only connection KeyLayers makes is the update check against its releases on GitHub. No accounts,
no analytics, no telemetry. The source is on <a href="https://github.com/plu/KeyLayers">GitHub</a>, MIT
licensed.</p>
</div>
