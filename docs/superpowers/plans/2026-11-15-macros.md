# Macros Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** UHK-style macros (Key, Text, Delay steps), bound to keys, played by the helper through the virtual keyboard with real delays.

**Architecture:** Macros live in `Configuration.macros`; a key's `KeyAction.macro(id)` makes the engine
release its synthetic modifiers and hand the `Macro` to the runtime in `EngineResult.macros`. A
`MacroPlayer` in `RemapperRuntime` expands steps (`MacroScript`) and posts them on a task with an
injected clock, pinned to the source keyboard. Text becomes keystrokes via a `UCKeyTranslate`
reverse table (`TextKeystrokes`, KeyboardLayout). The configurator gets a Macros sidebar section, a
macro editor and a Macro tab in the key action editor.

**Tech Stack:** Swift 6, TCA, swift-dependencies, swift-clocks, Carbon/TIS, Swift Testing, SnapshotTesting, Tuist.

**Spec:** `docs/superpowers/specs/2026-11-15-macros-design.md`

## Global Constraints

- Unit tests: `mise run test:unit`; snapshots: `mise run test:snapshot` (record with `mise run snapshot:record`); lint/format: `mise run lint`, `mise run format`. A single suite: `tuist test UnitTests -- -allowProvisioningUpdates -only-testing:<Target>/<Suite>`.
- After changing `Project.swift`, run `mise run generate`.
- `Configuration.currentFormatVersion` stays `1`.
- JSON shapes: action `{"type": "macro", "macroID": "<uuid>"}`; steps `{"type": "key", "key": …, "modifiers": […], "kind": "tap"|"press"|"release"}`, `{"type": "text", "text": "…"}`, `{"type": "delay", "milliseconds": N}`. Unknown step types are preserved as `{"type": …}`.
- Delay clamped on playback to 0…60 000 ms. Inter-event gap: one constant, `MacroPlayer.eventGap = .milliseconds(5)`.
- No secondary role on `.macro`. Playback on key-down only; repeats and the up are suppressed; another press while playing queues a run.
- Cancel (clear queue, release everything the player holds, restore Caps Lock) on: pause, emergency stop, `stop()`, `inputInterrupted`, `update(configuration:)`, keymap switch (`.keymapSwitched` notification or `selectKeymap`).
- Typing during playback interleaves with no extra protection (spec: option a); no change to `VirtualKeyboardState`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A macro key pressed while a key mapped to a bare modifier (e.g. Caps Lock → ⇧) is held: the ⇧ goes up before the macro and nothing is stuck after both keys are released. → Task 3.
- Pause or the emergency combo during a long delay: nothing is posted afterwards and every key a `press` step left down goes up. → Task 7.
- A `press` step with no matching `release`: the key goes up when the run ends. → Task 7.
- Text with doubled letters ("hello"), a newline, and an untypeable character ("☕"): both l's arrive (gap between up and next down), Return is tapped, ☕ is skipped. → Tasks 6, 7.
- Deleting a macro that keys use, or a configuration reload, while a run is queued: the run is cancelled; a key whose macro ID dangles does nothing. → Tasks 3, 7, 8.
